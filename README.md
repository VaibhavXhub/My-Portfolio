# My Portfolio

A modern, interactive web developer portfolio showcasing projects and skills with advanced animations and 3D effects.

## 🌐 Live Website

**[Visit Portfolio](https://vaibhavxhub.github.io/My-Portfolio/)**

## ✨ Features

- **Interactive 3D Background** - Dynamic fluid animation using Three.js
- **Smooth Animations** - GSAP-powered scroll animations and transitions
- **Responsive Design** - Fully responsive across all devices
- **Modern UI** - Clean and professional interface with custom styling
- **Smooth Scroll Navigation** - Easy navigation between sections
- **Status Badge** - Real-time availability indicator

## 🛠️ Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Advanced styling and animations
- **JavaScript** - Interactive functionality
- **Three.js** - 3D graphics rendering
- **GSAP** - Animation library
- **Google Fonts** - Typography (Inter, JetBrains Mono)

## 📂 Project Structure

```
My-Portfolio/
├── index.html       # Main HTML file
├── script.js        # JavaScript functionality
├── style.css        # Styling and animations
└── README.md        # Project documentation
```

## 📋 Sections

1. **Home** - Hero section with introduction
2. **About** - Personal bio and background
3. **Portfolio** - Showcase of projects
4. **Contact** - Get in touch section

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/VaibhavXhub/My-Portfolio.git
```

2. Navigate to the project directory:
```bash
cd My-Portfolio
```

3. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
http-server
```

## 🔧 Configuration

To customize the portfolio:

- **Personal Info**: Edit the text in `index.html`
- **Colors & Styling**: Modify `style.css`
- **Animations**: Adjust animation parameters in `script.js`

## 📱 Responsive Breakpoints

- Mobile: 320px and up
- Tablet: 768px and up
- Desktop: 1024px and up

## 🚢 Deployment

This project is deployed on **GitHub Pages**. To deploy your own:

1. Go to your GitHub repository settings
2. Navigate to **Pages** section
3. Select `main` branch as the source
4. Save and your site will be live at: `https://[username].github.io/My-Portfolio/`
